# Apple Stock Price Prediction 📈

## Project Overview

This project focuses on predicting future Apple stock prices using historical stock market data.
The goal of the project is to analyze past stock trends and build a machine learning model capable of forecasting the next 30 days of Apple stock prices.

Stock price prediction helps investors and analysts understand market patterns and make data-driven decisions.

---

## Objectives

* Analyze historical Apple stock price data
* Perform data preprocessing and visualization
* Train a machine learning model for prediction
* Forecast Apple stock prices for the next 30 days

---

## Dataset

The dataset contains historical Apple stock data including:

* Date
* Open Price
* High Price
* Low Price
* Close Price
* Volume

The data is used to analyze trends and train the prediction model.
